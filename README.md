# BloomVault Tester Application

One-page BloomVault Farms tester application built for GitHub Pages.

## Features

- BloomVault dark and gold theme
- Mobile-friendly layout
- Tester application form
- Email submission routing through FormSubmit
- Ready for GitHub Pages deployment
